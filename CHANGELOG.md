# Changelog

All notable changes to this project are documented here.

## [1.0.0] - 2026-07-20

### Added
- Email/password authentication with JWT sessions
- Short link creation with auto-generated or custom slugs
- Full CRUD for links, scoped per-user
- Click logging on redirect: timestamp, device, referrer
- Dashboard with stats, search, and per-link sparklines
- Per-link analytics page with 14-day chart and breakdowns
- Demo account auto-seeded on first run
